# The Word You'd Delete From the Dictionary

Entry for the make.fun bounty "The Word You'd Delete From the Dictionary".
The program scores candidate words against the judge's published criteria —
a recognisable real word, a joke that lands at first sight, humour that
comes from the word itself, and freshness — then writes the winning word,
and nothing else, to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network.
